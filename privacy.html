Personal Knowledge Drive Publisher 隐私政策

更新日期：2026-10-15。

使用范围。 本应用是所有者本人电脑上的个人工具，仅用于其本人明确选择的资料，不向公众提供账号或服务器托管服务。

处理的数据。 本应用在本机读取白名单中的笔记正文、标题和来源日期，用于生成选定资料副本。通过 Google 官方授权流程取得的授权信息保存在本人电脑的受限目录中，不存入笔记库或本应用公开页面。应用会读取其管理的特定 Google Docs 的正文、版本和相关文件元数据，以检查发布结果和人工修改冲突。

Google 权限。 本应用仅申请 drive.file，其范围是由本应用创建或由用户明确授权给本应用的特定文件。本应用不申请访问整个 Drive 的权限。初次账号登录、授权和后续必要的重新授权均由本人完成。

用途与传输。 资料用于本人选择的 Google Docs 副本发布与内容校验。白名单资料通过 Google 官方 API 传输到本人的 Google 账号。所有者把文档加入 NotebookLM 后，该产品依据 Google 的相关条款处理来源、聊天和生成内容；不能把这些云端处理称为完全离线。发布程序本身不调用其他大模型 API，不使用这些 Google 用户数据训练模型。

共享与公开。 本应用不出售数据，不向广告商提供资料，不设置笔记文档的公开分享权限，也没有接收笔记或令牌的应用中央服务器。所有者自行在 Google 服务中执行的分享或导出，由相应服务和本人设置控制。

本机与云端保存。 本机保留发布进度、内容校验值、选定资料快照；发现人工编辑冲突时可保存冲突副本。笔记和技术状态可能进入所有者配置的本地备份。Google Docs 与 NotebookLM 的资料保存在相应 Google 服务中，其保存不因本机程序关闭而自动终止。

停止与删除。 本人可关闭发布任务，并在 Google 账号的第三方连接设置中撤销授权。撤销授权会阻止后续访问，但不自动删除之前创建的文档、NotebookLM 来源或本机备份。需要删除云端资料时，应分别处理 Google Docs、NotebookLM 来源及其生成内容；需要删除本机资料或备份时，由本人另行决定，程序不因来源消失自动连带删除。

访问与安全。 Google 授权文件保存在本人电脑的受限目录中；它们不进入资料导出清单。仍需本人保护设备、Google 账号及备份。文档更新使用版本检查和内容读回校验，检测到冲突或错误时不将本次操作登记为发布成功。

公开说明页。 此说明页只展示应用用途与隐私政策，不嵌入知识库、文档链接、账号、分析脚本或广告。实际托管平台可能按其自身隐私政策处理访问日志。

联系方式与变更。 本应用支持联系方式为 Google 授权页面列示的支持邮箱。将来若改变权限、资料用途或接收方，应先更新本说明并由所有者确认，不沿用本次确认自动扩大范围。

本应用对从 Google API 获得的信息的使用与传输遵守 Google API Services User Data Policy，包括适用的 Limited Use 要求。Google 服务本身的数据处理另见 Google 隐私政策。
